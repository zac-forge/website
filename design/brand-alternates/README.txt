ZACFORGE LOGO ASSET SET

Recommended primary identity:
1. zacforge-wordmark.svg - primary horizontal header/footer wordmark
2. zac-mark.svg - standalone mark for avatar, app icon, social, and compact UI
3. favicon.svg - dark square favicon version

Alternate concepts from the design board:
4. zac-slash-forge.svg - alternate slash wordmark
5. zf-monogram.svg - alternate ZF monogram

Implementation notes:
- The SVGs are transparent except favicon.svg, which intentionally has a dark tile.
- Primary red: #E83445
- Hot red: #FF6875
- Deep red: #9E1F2D
- Primary white: #F4F2F0
- Secondary wordmark gray: #A6A4AA
- Background: #0C0C0F
- Wordmarks reference Space Grotesk. For exact production consistency, Claude can either leave them as SVG text with Space Grotesk loaded or convert the final approved lettering to outlines in a vector editor.
- Use the primary Z mark and ZACFORGE wordmark as the default system. The slash and ZF marks are alternates, not additional logos to mix throughout the site.
