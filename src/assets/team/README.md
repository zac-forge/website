# Team photos

Drop a photo here and rebuild. The team circles on the home page pick
it up by file name, no code change:

| File name (any of .webp, .avif, .jpg, .jpeg, .png) | Card |
|---|---|
| `andrew-johnston.webp` | Founder, Principal |
| `design-principal.webp` | Design Principal |
| `principal-engineer.webp` | Principal Engineer |

Square, at least 352 x 352 (the circle is 176px, shown at 2x), face centred.
It is cropped to the circle with `object-fit: cover`.

The Design Principal and Principal Engineer cards stay unnamed until Drew
says consent is given (CLAUDE.md). A photo of either is a consent question
too.
