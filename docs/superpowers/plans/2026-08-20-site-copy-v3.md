## Global Constraints

Copied verbatim from `CLAUDE.md`. Every task's requirements implicitly include this section.

- **Never use the word "AI".** Zero occurrences on any shipping surface: copy, alt text, meta tags, `llms.txt`, `package.json`, `README.md`.
- **No contractions.** "does not," not "doesn't."
- **No em dashes.** Anywhere, including code comments and commit messages. Use a comma, a period, a colon, or parentheses.
- **No semicolons in prose. No exclamation points. No emoji.**
- **Oxford comma.** Yes.
- **Headings sentence case.** Eyebrows are ALL CAPS mono, numbered.
- **Numerals for anything measurable.** "41 states," "20 years."
- **Banned vocabulary:** solutions, synergy, cutting-edge, best-in-class, world-class, seamless, robust, empower, unlock, elevate, passionate about, leverage (as a verb), AI-native, AI-first, AI-powered, ship fast, 10x, force multiplier.
- **The test for any new line:** could a firm founded last year write this exact sentence? If yes, cut it or make it specific.

**Compliance, do not violate:**

- No DoD seals or insignia. Describing the Navy and Marines work in text is fine.
- No IBM logo in a client wall. IBM is where the team worked, not a client.
- The $1B is the client's transaction volume, never ZAC revenue. Write "over $1 billion in assets sold through the platform."
- The 90% figure is client-reported. Always attribute it.
- Never characterize a named client's leadership or internal problems.
- Do not name Misha or Luciano. Ship roles and backgrounds only, with name and photo as optional props.

**Design constraints:**

- The visual direction is approved and locked. `docs/reference-mockup.jpg` is a QA target, not inspiration. Refine against it, never redirect.
- Motion is reactive, not ambient. Nothing animates until a pointer or keyboard arrives. Respect `prefers-reduced-motion` everywhere.
- Never hardcode a colour. Use the tokens in `src/styles/tokens.css`.
- Do not redraw or recreate the logo. Use the rasters in `public/brand/`.

**Interactions that must survive:** the THEN/NOW row draw in `ShiftComparison`, the row ignition in `ServiceRow`, the signal-flow sequence in `HowItWorks`, the horizon arc and ember field in `FinalCTA`.

## Verification model, read this before Task 1

**This repo has no test framework.** No vitest, no testing-library, no `test` script. Adding one is not in scope. The plan therefore substitutes a real, repeatable gate for the usual red/green cycle:

| Gate | Command | What it catches |
|---|---|---|
| Type and build | `npm run build` | Runs `tsc -b` then Vite. Catches every type and import error. |
| Voice | `bash scripts/voice-check.sh` | "AI", em dashes, exclamation points, emoji, banned vocabulary. Exits non-zero on violation. |
| Visual | `npm run dev`, then measure | Layout regressions. See the measurement rules below. |

`scripts/voice-check.sh` already exists and **already fails** on `main`. That failing state is the red half of the cycle. It goes green when Task 9 lands, and it must stay green from then on.

**Measure the running page, never the CSS.** Three traps have bitten repeatedly in this repo:

1. `.hero` sets `overflow: clip`, which hides overflow from `scrollWidth`. Measure `getBoundingClientRect()` on the child, not the parent's scroll width.
2. `--ease-out` is `cubic-bezier(.16, 1, .3, 1)`, which puts roughly 90% of its travel in the first fraction. A screenshot taken "mid-animation" looks finished when it is not. Wait for `transitionend`.
3. Source order beats a mobile block at equal specificity. A rule that looks overridden may not be.

Every task that changes layout ends with a measurement step at three widths: **1440, 1024, and 390**.
